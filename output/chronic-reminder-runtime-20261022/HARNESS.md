# 慢病检查检验紧凑提醒预览

萧山历史开发演示，仅用于回顾原两慢病一体化提醒组件与匹配规则；不是白云分支产品入口，白云分支不请求该推荐，也不生成或恢复对应检查/检验候选。

仅合成资料，挂载生产匹配 Builder 和提醒 Vue 组件，不连接患者、服务端或 PHIS，不新增依赖。

仓库根目录运行：`yarn vite --config output/chronic-reminder-runtime-20261022/vite.config.ts`。
打开 http://127.0.0.1:5194，验证三项唯一匹配、组套/部位歧义、失败状态、窗口边缘及提示图标的悬浮/焦点/点击/关闭与滚动。
